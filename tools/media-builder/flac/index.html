    Output requirements and privacy

    Inputs must be native FLAC, 44.1 kHz, 16-bit, stereo, with CD-sector-aligned lengths. The output contains a standard embedded CUESHEET, a frame-aligned SEEKTABLE, and the compact MP3A metadata/artwork block used by Phosphor. Every decoded input sample is retained in its original order; the builder never trims, pads, fades, or otherwise edits the audio. Audio is decoded and losslessly re-encoded locally; no files are uploaded.
