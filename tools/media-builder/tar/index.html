    Format and privacy

    The standard uncompressed TAR contains playlist.m3u, the original audio files, and optional 92×92 RGB332 cover artwork. TAR member order does not matter; the M3U controls playback order. Existing playlists made here can be reopened and edited. Audio bytes are never decoded, re-encoded, or modified. No files are uploaded. Track changes are not gapless.
