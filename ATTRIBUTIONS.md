# MiSTer-Phosphor FPGA Source Attributions

This document records the provenance and licensing of third-party and reused
source included in the MiSTer-Phosphor FPGA project. It complements, and does
not replace, the copyright and license headers in individual files.

## Project code

MiSTer-Phosphor's audio decoders, playback control, playlist and album logic,
visualizers, user interface, metadata parsers, and project integration are
distributed under the GNU General Public License, version 2 or later. Because
the complete design also includes MiSTer framework modules licensed under GPL
version 3 or later, distribution of the combined source and compiled RBF should
follow GPL-3.0-or-later.

The relevant full license texts are included as:

- `COPYING` — GNU GPL version 3
- `COPYING.GPL2` — GNU GPL version 2
- `COPYING.LESSER` — GNU LGPL version 3

### Compatibility with MiSTer-Raster

MiSTer-Phosphor and MiSTer-Raster both license their original project code as
GPL-2.0-or-later. Code owned by the projects can therefore move between them
under the shared GPL-2.0-or-later terms. When that code is incorporated into a
complete design containing GPL-3.0-or-later MiSTer framework modules, GPL's
"or later" option permits the combined work to be distributed under GPL
version 3 or later.

`LICENSE.txt` intentionally retains the same GPL version 2 text used by
MiSTer-Raster. It states the baseline license offered for original project
code; it does not override GPL-3.0-or-later or LGPL terms carried by individual
framework files. `COPYING` supplies GPL version 3 for the combined-design
distribution case.

## MiSTer framework

The `sys/` tree is based on the standard
[MiSTer core framework](https://github.com/MiSTer-devel/Template_MiSTer). It
provides HPS communication, board integration, audio and video output, scaling,
OSD support, virtual storage, and related platform services.

Copyright holders named by the included framework files include:

- Ultra-Embedded.com
- Other MiSTer framework contributors

The framework contains a license mixture that must be preserved file by file:

- GPL-2.0-or-later modules include `alsa.sv`, `arcade_video.v`, `audio_out.sv`,
  `iir_filter.v`, `ltc2308.sv`, `spdif.v`, `sys_top.v`, `video_freezer.sv`, and
  `yc_out.sv`.
- GPL-3.0-or-later modules include `ddr_svc.sv`, `hps_io.sv`, and
  `scandoubler.v`.
- `sd_card.sv` is LGPL-3.0-or-later.
- `hq2x.sv`, `video_cleaner.sv`, `video_freak.sv`, and `video_mixer.sv` identify
  themselves as GPL-licensed and retain their upstream notices.
- Other files in `sys/` remain part of the imported framework and retain their
  existing authorship or generated-code notices even where a per-file SPDX
  identifier is absent.

Do not remove or replace the copyright and license comments in these files when
updating the framework.

## FFmpeg-referenced MP3 implementation

Parts of the native MPEG-1 Layer III implementation were developed by
transcribing, studying, or validating behavior against FFmpeg's decoder. The
source comments identify the relationship in detail, particularly in:

- `rtl/mp3_antialias.sv`
- `rtl/mp3_dequant.sv`
- `rtl/mp3_stereo.sv`
- `rtl/mp3_imdct.sv`
- `rtl/mp3_huffman_decoder.sv`
- `rtl/mp3_synthesis.sv`

FFmpeg is Copyright (c) the FFmpeg developers and is primarily licensed under
the GNU Lesser General Public License version 2.1 or later, with optional GPL
components. MiSTer-Phosphor does not bundle or link an FFmpeg executable or
software library, but this implementation provenance is credited because some
HDL behavior is expressly described as transcribed from FFmpeg source.

- Upstream: <https://ffmpeg.org/>
- License information: <https://ffmpeg.org/legal.html>
- Referenced implementation family: `libavcodec/mpegaudiodec_template.c` and
  related MPEG audio decoder sources

The project's GPL-3.0-or-later combined distribution is compatible with the
relevant LGPL-2.1-or-later provenance. Existing explanatory comments in the MP3
RTL must be retained.

## Intel/Altera generated FPGA IP

PLL and PLL-reconfiguration sources generated by Quartus/Altera tools carry
Intel or Altera notices and are subject to the Intel FPGA software and IP
license terms embedded in those files. They are not relicensed by the project's
GPL declaration.

Relevant generated sources and support files include:

- `rtl/pll.v` and `rtl/pll/`
- `sys/pll_audio.v` and `sys/pll_audio/`
- `sys/pll_hdmi.v` and `sys/pll_hdmi/`
- `sys/pll_cfg/`
- Associated `.qip` files and generated configuration data

Those notices restrict the generated material to the uses permitted by the
applicable Intel FPGA license agreements. Keep the generated headers intact.

## Codec specifications and acknowledgements

The FLAC and Ogg Vorbis RTL under `rtl/audio/` is a native hardware
implementation rather than a compiled copy of Xiph's software libraries. The
formats and terminology originate with the Xiph.Org projects:

- FLAC: <https://xiph.org/flac/>
- Ogg: <https://xiph.org/ogg/>
- Vorbis: <https://xiph.org/vorbis/>

MPEG Layer III is implemented from the MPEG audio format and supporting
reference work. Names of formats and projects identify compatibility and do not
imply endorsement.

## Redistribution checklist

When publishing source or an RBF release:

1. Include `COPYING`, `COPYING.GPL2`, `COPYING.LESSER`, and this document with
   the corresponding source distribution.
2. Preserve all per-file copyright, license, and generated-IP headers.
3. Make the complete corresponding FPGA source used for the RBF available
   under the applicable licenses.
4. Retain the Media Builder's attribution and bundled libflac.js license when
   distributing that utility.
5. Record the MiSTer framework revision when importing future `sys/` updates.

This inventory documents the repository as audited; it is not legal advice.
